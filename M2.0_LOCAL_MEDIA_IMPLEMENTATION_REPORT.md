## 1. What already existed (audit highlights, verified by reading code)

- **Local-first storage:** referenced media via `FileSystemFileHandle` (large files never copied); ≤64 MB blob copies only when a handle exists (`COPY_LIMIT` in `lib/media/sources.ts`) so small files reopen silently; metadata in IndexedDB; source records in IndexedDB with per-id registration + identity cross-pointers.
- **OPFS-derived caches** for proxies/converted copies (`lib/media/opfs.ts`) with streaming writes, double-write fallback for browsers without `createWritable`, `ensureRoom()` quota preflight, IndexedDB (`braincut-files`) fallback — nothing re-reads the original fully into memory.
- **Proxy pipeline:** mediabunny (WebCodecs) → H.264/AAC medium MP4, height-capped (never upsizes), streaming output, quota preflight, per-item progress in context menus and a circular progress badge in the bin, create/remove per item.
- **Export:** OPFS scratch preflight (`ensureRoom` in `render.ts`), picker + regular-download fallback (M1.1), progress UI, cancellation via abort, no source modification.
- **Long-form timeline:** **virtualization already exists** — `TrackLane` culls clips/transitions outside `viewStart/viewEnd` ±25% margin; thumbnails and waveforms are lazily generated and pooled (`MAX_BITMAPS=400`, bounded queues); rapid clip scrubbing is decode-on-demand (`media-reader`).
- **Persistence/recovery:** autosave on edit, IndexedDB project store, RECENT reopen, missing-media detection on open with one-click grant-all (`needsPermission`), folder-based relink (`relinkMissing` with name+size+duration matching — `Relink all…` button verified in source).
- **Drag-and-drop & drop overlay** (correct: window-level `DropOverlay` routes to import or project-open parse).

## 5. Known limitations (carried into §11 of the architecture report)

- No multi-hour/4K/multi-GB import has executed here (harness uploads cap at 5 MiB; real OS file dialogs refuse protected folders in the embedded pane).
- Real user clicks do not reach Svelte button handlers in this pane — UI paths verified via trusted synthetic clicks + real drop events.
- Timeline virtualization exists but is unzoomed; extremely long timelines with hundreds of tracks remain untested.
- Import cancellation aborts *between* files; a single huge probe is not interruptible mid-file.
- Proxy regeneration is manual (context menu), not automatic on missing data; proxies disabled by default (`useProxies: false`).
- OPFS allocation is per-origin and subject to `storage.persist()` opaqueness.
