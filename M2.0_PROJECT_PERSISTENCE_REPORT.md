# M2.0 — Project Persistence Report

Scope: how a project survives save/close/reopen and how media references are kept honest. Sources: `vendor/braincut/src/lib/project/{types,serialize,persistence,store}.ts`, `media/sources.ts`, `media/opfs.ts`, `editor/project-actions.ts`, `ui/{EditorPage,Welcome}.svelte`.

## 1. Format on disk

`serializeProject()` (v1): pure JSON. Top-level keys: `version`, `name`, `sequences` (ordered tracks → clips/transitions with timecodes), `media` (id, kind, name, fileName, fileSize, lastModified, duration, fps, width/height, mime, hasVideo/hasAudio, proxy/converted references with keys/width/height, status), `activeSequenceId`, `createdAt`, `savedAt`, `preferences?`. **Original video bytes are never embedded.** `name`/`activeSequenceId`/`version` form the reopen contract; media bytes live outside.

Extension: `.braincut`. Save path: `showSaveFilePicker` (M1.8 fallback: regular `.braincut` download with the identical JSON). Open path: `showOpenFilePicker` → `parseProject()` validates v1 or migrates (geometry/length/type coercion with explicit errors — see `serialize.ts`).

## 2. Media reference mechanics

| Origin of file | `registerSource()` stores | After reload |
|---|---|---|
| Picker (`showOpenFilePicker`) | handle (primary) + blob only if ≤ 64 MB | handle readback with permission prompt or silent `queryPermission('read')` |
| Drag-and-drop (Explorer) | **handle** — Chromium grants handles to drag payloads with `getAsFileSystemHandle()` | handle readback (same as above) — this is what the M1.9 fix restores |
| HTML file input fallback | File object only | **in-session only — nothing persisted.** Documented limitation for browsers without the File System Access API (Firefox). |
| Proxy / converted | OPFS via `proxy/<id>.mp4` / `converted/<id>.mp4` | read back from OPFS; regenerate if missing |

Handles >64 MB are never copied into IndexedDB; the File object of a large drag-and-drop is not stored either — the handle is what survives.
UI recovery flow: on open, `restoreSources()` runs per media id: handle → permission query/request → blob fallback; anything unreadable is marked `status: 'missing'` with a reason; `locked` accumulates handles for the **one-click grant-all** banner (`needsPermission` → Relink all…), also reachable from the Media panel and context menu; folder relink (`relinkMissing`) matches by name and size (then duration ±0.5 s).

## 3. Autosave & crash recovery

- `scheduleAutosave()` on every `edit()` batch (250 ms debounce via `dirty` store) → IndexedDB snapshot, plus recents pointer.
- `restoreSources()` re-runs on every open; media that silently vanished while the tab was closed are re-marked `missing` on the next load (with toast: "N files missing — Relink all…").
- Refresh recovery verified in this session: full reload → `Untitled project` appears in RECENTS → reopen → all three clips (`m1-test-B.mp4`, `test4-clip.mp4`, `drop-test.mp4`) restore with probed metadata at 0:08.0, 352×640, 30 fps, 0 console errors.
- Interrupted-save drill (kill tab during write): not executed — expected outcome: reopen falls back to the last good autosave; unsaved tail of the editing session is lost. Marked NOT VERIFIED.

## 4. OPFS proxy keys

`proxy/<mediaId>.mp4`, `converted/<mediaId>.mp4` — keyed by media id (never by path), so reference keys and file handles can diverge without false "found" reports. `invalidate(mediaId)` drops both on media reload/relink; `applyProbe` in `sources.ts` nulls `media.proxy` whenever a file is relinked, forcing regeneration.

## 6. Persistence verification instructions (your machine)

1. Import `drop-test.mp4` → Ctrl-S → Save to any folder → browser restart (not just tab close).
2. Relaunch → RECENTS → click the project → confirm the clip is playable and the file is served from the handle (no re-prompt on first open in the session).
3. Move/rename the original file → reopen project → expect "1 file missing" banner → **Relink all…** → pick the new folder → confirm the clip resolves.
4. Kill the tab during an autosave; relaunch; confirm the project returns to the last durable state.
