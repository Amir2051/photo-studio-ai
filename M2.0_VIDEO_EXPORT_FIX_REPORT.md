## 3. Format honesty

- Format actually produced: **MP4** (ISO-BMFF; `format_name=mov,mp4,m4a`), H.264 High, AAC-LC, 192 kbit/s. The Export dialog also offers WebM/VP9, AV1, MKV, MOV, GIF, WAV — all selectable; none were substituted with different labels; nothing was mis-labelled as MP4.
- Limitation on this machine: encoder time ≈ 14 s for 8 s of video in this pane (1 s render ≈ 1.75 s of wall clock). True for software decode in Electron; hardware acceleration option exists (`Prefer hardware` in the dialog) but was not exercised here.

## 4. Fallback artifact integrity

- Save-fallback downloads exactly the serialized project bytes (verified file content, §1).

- No path substitutes a project file for a video or vice-versa. Checked both `AbortError` (Save silent-by-design) and `NotAllowedError` (Save → download works) and picker-refused Export (yields MP4 via download).
